# Лабораторная работа 4

## Задание

Вариант 25.

1. Создать класс `Product` с полями id, name, categories, price; методами
   добавления/удаления категорий и геттером количества категорий.
2. Написать функции группировки, поиска уникальных категорий, фильтрации по цене
   и категориям.
3. Реализовать UI: карточки товаров, формы создания, кнопки удаления. Все
   операции добавления/удаления выполнять асинхронно через Promise +
   setTimeout(). Сохранять состояние в local storage.

## Реализация

Проект разделен на `model.js` (логика данных и именованные экспорты класса и
функций коллекций) и `main.js` (управление пользовательским интерфейсом). В UI
реализованы необходимые атрибуты `data-testid` для списков, форм и карточек
согласно контракту. Добавление и удаление элементов инкапсулировано в `Promise`
с задержкой в 150мс для имитации работы сети, после чего происходит
автоматическое обновление DOM. При перезагрузке страницы данные корректно
восстанавливаются из `localStorage`.

## Запуск

Открыть файл `index.html` с помощью локального сервера (например, расширения
Live Server в VS Code), чтобы корректно работали ES-модули
(`<script type="module">`).
