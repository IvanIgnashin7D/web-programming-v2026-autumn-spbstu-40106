# Лабораторная работа — Задача 4

## Задание

Вариант 25.

1. Создать класс `Product` с полями `id`, `name`, `categories`, `price`; методами добавления (`addCategory`) и удаления (`removeCategory`) категорий и геттером количества категорий (`categoryCount`).
2. Написать функции группировки по категориям, поиска уникальных категорий, группировки по диапазонам цен, фильтрации по заданной категории и фильтрации по цене выше заданной.
3. Реализовать UI: карточки товаров, формы создания товара и добавления категорий, кнопки добавления/удаления товаров и категорий. Все операции добавления/удаления выполнять асинхронно через `Promise` + `setTimeout()`. Сохранять состояние в `localStorage`.

## Реализация

Проект разделен на `model.js` (логика данных и именованные экспорты класса и функций для работы с массивом товаров) и `main.js` (управление пользовательским интерфейсом). В UI реализованы атрибуты `data-testid` для списка (`entity-list`), формы (`entity-form`), карточек (`entity-card`) и кнопок удаления (`delete-entity`). Все операции изменения состояния инкапсулированы в `Promise` с `setTimeout`, после чего происходит автоматическое сохранение в `localStorage` и перерисовка DOM.

## Запуск

Открыть файл `index.html` с помощью локального веб-сервера (например, расширения Live Server в VS Code), чтобы корректно работали ES-модули (`<script type="module">`).
